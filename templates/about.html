About ProfinD

Smart E-Commerce Product Price Comparison & Analysis System

Project Overview

ProfinD is developed as an MCA Final-Semester Capstone Project. The platform addresses a common consumer challenge: prices for identical electronic items fluctuate wildly across online retailers (Amazon, Flipkart, Croma, Reliance Digital), and misleading promotional prices often hide mandatory delivery fees.

ProfinD aggregates store offerings, calculates the effective total cost (Base Price + Shipping), and leverages an optimal \(O(n)\) linear scan algorithm to mathematically guarantee identification of the lowest price offer.

Curriculum Competencies Demonstrated

  • Design & Analysis of Algorithms (DAA): Optimal linear minimum scan algorithm with \(O(n)\) time and \(O(1)\) auxiliary space complexity.
  • Advanced Database Management Systems (ADBMS): Relational schema normalization (3NF), foreign key referential integrity, exact integer currency representation (paise), and parameterized SQL statements.
  • Advanced Internet Programming (AIP): Clean WSGI application architecture using Python Flask, Jinja2 template inheritance, and accessible responsive CSS3.
